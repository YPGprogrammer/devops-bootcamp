# DevOps Bootcamp — 30-дневный путь от нуля до Middle

Этот репозиторий фиксирует мой прогресс за 30 дней интенсивного обучения DevOps. Я изучаю Linux, Bash, сети, систему контроля версий, CI/CD, Docker, Kubernetes и инфраструктуру как код.

Каждый день включает:
- Изучение теории (LPIC + литература)
- Практика в терминале
- Bash-скрипты
- Конспекты и заметки

## Структура
- `dayXX/` — директория для каждого дня
  - `linux_commands.txt` — команды, изученные в этот день
  - `*.sh` — bash-скрипты
  - `notes.txt` — ключевые выводы и мысли

## Цель
Через 30 дней: уровень Middle DevOps и реальный проект в портфолио

## План на 30 дней:

### **День 1: Linux Core — терминал и скрипты**
- Освоение базовых команд Linux: работа с пользователями, правами, файловой системой
- Написание простого bash-скрипта для создания пользователя с правами sudo

### **День 2: Работа с пакетами и системными сервисами**
- Установка пакетов с `apt`, работа с репозиториями
- Введение в `systemctl`, управление сервисами

### **День 3: Работа с логами и журналами**
- Изучение `journalctl`, настройка логирования и анализ
- Разбор логов системы, сервисов, приложений

### **День 4: Cron — планирование задач**
- Настройка cron-заданий
- Написание bash-скриптов для автоматизации задач (например, ежедневные бэкапы)

### **День 5: Основы безопасности — файрвол и защитные механизмы**
- Введение в `ufw` (Uncomplicated Firewall)
- Установка и настройка `fail2ban` для защиты от атак

### **День 6: Docker — контейнеризация**
- Основы Docker: установка, создание контейнеров, работа с образами
- Создание Dockerfile и запуск контейнера с приложением

### **День 7: Docker Compose**
- Работа с `docker-compose`: создание многоконтейнерных приложений
- Написание docker-compose.yml для развёртывания многосервисной архитектуры

### **День 8: Git — основы и команды**
- Работа с Git: создание репозиториев, commit, push, pull
- Создание веток и работа с конфликтами

### **День 9: GitHub Actions — основы CI/CD**
- Создание первого рабочего пайплайна на GitHub Actions
- Автоматизация тестирования и деплоя для простого приложения

### **День 10: Основы сетевой инфраструктуры**
- Изучение сетевых команд: `ip`, `netstat`, `ping`, `traceroute`
- Работа с сетевыми интерфейсами и настройка сетевых подключений

### **День 11: Настройка Web-сервера (Nginx)**
- Установка и настройка Nginx как обратного прокси для приложений
- Конфигурирование SSL и перенаправление трафика

### **День 12: Работа с базами данных (PostgreSQL)**
- Установка и настройка PostgreSQL
- Написание базовых SQL-запросов

### **День 13: Развёртывание Flask-приложения с Nginx и PostgreSQL**
- Развёртывание веб-приложения на Flask с PostgreSQL на сервере
- Настройка Nginx как прокси для приложения

### **День 14: Микросервисная архитектура**
- Понимание микросервисов
- Развёртывание нескольких сервисов в Docker с использованием Docker Compose

### **День 15: Введение в Kubernetes (K8s)**
- Установка и настройка локального кластера Kubernetes
- Развёртывание приложения в K8s с использованием `kubectl`

### **День 16: Понимание контейнеризации с Kubernetes**
- Основы работы с Pod'ами, ReplicaSet, Deployment
- Развёртывание простого приложения в Kubernetes

### **День 17: CI/CD с GitLab CI**
- Настройка GitLab CI для автоматизации деплоя
- Написание конфигурации `.gitlab-ci.yml`

### **День 18: Мониторинг и логирование (Prometheus и Grafana)**
- Установка и настройка Prometheus для сбора метрик
- Настройка Grafana для визуализации метрик

### **День 19: Секьюрити: SSH и ключи доступа**
- Настройка SSH, использование SSH-ключей
- Защита от brute-force атак, настройка fail2ban для SSH

### **День 20: Настройка авто-скейлинга с Docker и Kubernetes**
- Введение в авто-скейлинг контейнеров в Kubernetes
- Применение Horizontal Pod Autoscaling

### **День 21: Введение в Terraform**
- Основы Terraform для автоматизации инфраструктуры как кода
- Написание первых скриптов для создания ресурсов в облаке

### **День 22: Настройка Jenkins для CI/CD**
- Установка Jenkins и настройка пайплайна для деплоя
- Интеграция Jenkins с GitHub

### **День 23: Развёртывание инфраструктуры с Terraform и AWS**
- Развёртывание ресурсов в AWS с помощью Terraform
- Управление EC2, S3, и другими ресурсами через Terraform

### **День 24: Введение в Ansible**
- Установка и настройка Ansible
- Написание базовых плейбуков для автоматизации серверов

### **День 25: Автоматизация с Ansible и Docker**
- Написание плейбуков для автоматического развёртывания Docker-контейнеров
- Обзор и настройка Docker и Kubernetes через Ansible

### **День 26: Мониторинг приложений с использованием ELK stack**
- Установка и настройка Elasticsearch, Logstash и Kibana для логирования
- Создание базовой визуализации логов с Kibana

### **День 27: Контейнеризация с Helm (для Kubernetes)**
- Введение в Helm для управления Kubernetes приложениями
- Установка и настройка Helm-чартов для деплоя

### **День 28: Обновление и управление состоянием в Kubernetes**
- Работа с обновлениями в Kubernetes: Rolling Update, Blue-Green деплойменты
- Резервное копирование и восстановление данных

### **День 29: Контейнеризация и безопасность**
- Best practices безопасности для контейнеров
- Настройка пользовательских прав, работа с Docker secrets

### **День 30: Завершение проекта и выводы**
- Финальный проект: DevOps пайплайн, мониторинг, автоматизация
- Обзор всех полученных навыков и подготовка к интервью
